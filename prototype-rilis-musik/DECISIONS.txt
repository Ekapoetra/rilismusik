D1. TOKEN — REL PEMBAYARAN KEDUA                  DRAFT   [ARSITEKTUR][BIAYA]
------------------------------------------------------------
Arah pemilik (final, menggantikan draft sebelumnya):
  • Token adalah OPSI pembayaran kedua — member yang tidak tertarik
    tetap membayar rupiah seperti biasa.
  • Benefit permanen: token SELALU lebih murah dari nilai rupiah.
  • Kunci dasar: nilai 1 token = 1 rilisan (lantai Rp35.000),
    berlaku juga untuk biaya layanan lain.
  • Order rupiah yang di-refund → menjadi SALDO RUPIAH milik label.

Rancangan lengkap → ANNEX-E. Inti:
  1 token = satuan layanan. Harga layanan dalam token =
  ceil(harga rupiah / 35.000) — konversi selalu menguntungkan member.
  Harga jual token bertingkat tapi TIDAK PERNAH ≥ Rp35.000.
  Tiga pool: Bawaan paket / Beli / Ganti (kompensasi).
  Saldo Rupiah = kredit toko — hanya bisa dibelanjakan, tidak bisa
  ditarik tunai, tidak bisa membeli token.

KEPUTUSAN: DRAFT — menunggu konfirmasi pemilik atas ANNEX-E.

D4. KUOTA WAMI & DESIGN PER TIER                  DRAFT   [BIAYA]
------------------------------------------------------------

Dasar bobot (dari model & harga main):

  dijaga di bawah ~25% kapasitas agar tidak memakan antrean rilisan.

D9. TARIF ROYALTI PER LABEL                       DECIDED-SEBAGIAN
------------------------------------------------------------
  Penjelasan: main memotong royalti — label menerima 60% (default),
  platform 40%. Persentase dapat dinegosiasi per label lewat alur
  rate-change dengan approval. Prototype saat ini mengasumsikan 100%.
  → DIPUTUSKAN pemilik: tarif 60% hanya berlaku untuk LABEL BARU.
    Label lama (legacy) mempertahankan persentase masing-masing yang
    sudah disesuaikan — tidak dipaksa seragam.
  → Konsekuensi model: kolom tarif per-label WAJIB ada (bukan opsi
    nanti); default 60% hanya diisi saat label baru dibuat.

KEPUTUSAN: SAHKAN — 60% untuk label baru; legacy pakai tarifnya sendiri.
