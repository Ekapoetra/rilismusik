RUN THE PROTOTYPE
Node.js: npm run preview
Open http://localhost:4343/ . Use Devin's browser/port preview for the user; the former Windows LAN address is not accessible from Devin Cloud.
No dependencies are required for preview or building. npm run build rebuilds the standalone file.
Optional regression test: npm install ; npx playwright install chromium ; npm run verify . These are separate commands.
The exported QA runner replaces its original Windows-only Playwright path/Edge channel with npm Playwright/Chromium. Production integration tests are separate work.
